# repobutgood

Personal project.

Repositories page: https://nightshadess24.github.io/repobutgood/repos/ lists every
repository this site gathers sources from, each with its own "Add to Paperback"
link and its sources (read live from that repository). The list of repositories
is `repos-page/repos.json`; editing it republishes the page
(`.github/workflows/repos-page.yaml`). The Aggregated / Separate switch at the
top of both pages goes between the homepage and it; their shared background and
switch are `repos-page/site.css` (the homepage build inlines it).
